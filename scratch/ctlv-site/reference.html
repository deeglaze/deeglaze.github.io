Reference: the CTLV specification language

Complete definition of the YAML inputs consumed by tools/ctlv.

1. Files

PathRole
Documentation/ctlv/ctlv-schema.yamlJSON Schema (draft 7) for a family specification.
Documentation/ctlv/ctlv-registry-schema.yamlJSON Schema for the family registry.

Documentation/ctlv/specs/<family>.yamlSpecification of one family. The file stem is the family name.

Documentation/ctlv/abi/<family>.yamlABI snapshot of one family.

The specification of the root family ctlv is located relative to the meta-schema (specs/ctlv.yaml beside it). The specification of every other family is located in the directory of the specification being loaded.

Every registry entry has exactly one specification and one ABI snapshot. A specification or snapshot without a registry entry is an error.

2. Document syntax

YAML subset

Each file is a single YAML document whose top level is a mapping. The loader is yaml.SafeLoader with these additional rejections:

  • aliases,
  • anchors,
  • merge keys,
  • explicit tags,
  • duplicate mapping keys,
  • more than one document.

Required first line

The first line of a specification and of a registry is a comment matching #\s*SPDX-License-Identifier:\s*(\S.*?)\s*$. The captured identifier is the license of every generated file derived from the file.

Validation order

  1. YAML subset load.
  2. Meta-schema validation (syntax gate).
  3. Per-declaration normalization (spec.py).
  4. Chain resolution and cross-declaration checks (semantics.py).
  5. Generated-name collision check (cgen.symbols).

Every unknown key is an error at every level (additionalProperties: false).

3. Names and selectors

KindPatternAdditional constraint
name^[a-z0-9]+(-[a-z0-9]+)*$
family namenameAt most 63 characters.
selector^[a-z0-9]+(-[a-z0-9]+)*(\.[a-z0-9]+(-[a-z0-9]+)*)?$At most one dot.

A dot is reserved for selectors. A name does not contain one.

Selector forms

FormSelects
group.attrThe one attr attr of group group.
name (a group)Every attr of the group, in declaration order, as required placements unless selected optionally.
name (an attr set)The required and optional members of the set.

A selector without a dot is resolved as a group first and as an attr set second. Group names and attr set names share one namespace and are never equal. There are no tuple selectors and no family-qualified selectors.

A field typed selectors accepts one selector string or a non-empty array of selector strings.

Namespaces

NamespaceScopeMembers
DefinitionsInheritance chainenum names and flags names, together

Redeclaring a name in the same namespace is an error, except that a descendant declares an inherited stub attr set once to fill it (stubs).

4. family

Required. Mapping with these keys.

KeyTypeDefaultDefinition
namefamily namerequiredRegistered name. Equals the file stem of the specification.
inheritsfamily namenoneThe single direct parent.
pre-initbooleanfalseThe family implements the generated pre-init callback, which translates its init information for its parent. Without it, the parent receives NULL.
post-initbooleanfalseThe family implements the generated post-init callback, run after every family priv is initialized.
pre-finibooleanfalseThe family implements the generated pre-fini callback, run before any family priv is finalized.

Rules

  • The root family is named ctlv, holds family ID 0, and does not declare inherits.
  • Every other family declares inherits.
  • A family that inherits P is named P-<suffix> with a non-empty suffix.
  • A parent is registered at a lower index than every family inheriting it.
  • An inheritance cycle is an error.
  • The effective schema of a family is the union of the declarations of its chain, root first. Inherited definitions keep their IDs.
  • pre-init, post-init and pre-fini are ABI snapshot members.

Nest attrs

KeyDefinition

recursiveThe nest may contain its own attr again at any depth.
  • A nest chain is at most 31 levels deep.
  • A nesting cycle through non-recursive nests is an error.

Recursive nests

  • attrs holds exactly one selector.
  • That selector names an attr set. A group name and a group.attr selector are errors.
  • optional-attrs is not declared.
  • The named attr set selects the nest's own attr, directly or through nested attrs.
  • A re-entry is reported by the node with reenters and no members.
  • Only a query reply contains a recursive nest.

7. attr-sets

Optional array. An element is a mapping:

KeyTypeDefinition
namenameSet name.
stubtrueDeclares an extension point.
attrsselectorsRequired members.
optional-attrsselectorsOptional members.
  • A set is either a stub with no members, or has at least one member in attrs or optional-attrs.
  • A set selecting itself, directly or through other sets, is an error.
  • Every set is expanded and checked whether or not an op selects it.
  • Set IDs are assigned from 1 per family, in declaration order, counting only sets not filling an inherited stub.

Stubs

  • A stub has no members and expands to nothing until filled.
  • A descendant fills an inherited stub by declaring an attr set with the same name and at least one member.
  • A fill is made at most once in an inheritance chain.
  • A fill is not itself a stub.
  • Only a stub is filled. A name already declared as a non-stub set by an ancestor is an error.
  • The filled set keeps the ID given by the family that declared the stub.
  • A fill contains no recursive attr.
  • An attr set that a message root built by the core uses does not select a stub.
  • A query reply that selects a stub does not also contain a re-entry.

9. Composition rules

Expansion of a selection

  • A selection in attrs yields required placements. A selection in optional-attrs yields optional placements.
  • When an attr set or group is selected optionally, every member becomes optional.
  • When one attr is selected more than once at one level, the selections merge into one placement. A required selection takes precedence over an optional one.
  • Selecting one attr both through a filled stub set and outside it at one level is an error.
  • After fills are composed, every attr ID at one nesting level has exactly one placement. A second placement is an error.

Stub selection

  • A stub selected optionally makes every member of its fill optional.
  • One reference is kept per stub selected at a level. A required reference takes precedence over an optional one.

Structural checks

  • A selector that matches no attr, group or set is an error.
  • The per-op request tree and reply tree are checked individually.
  • The composed tree of each op (fills spliced in) is checked against the limits of section 12.

QuantityDefinition

Children sumΣ max-occurrences × align(attr maximum length) over members

Checks

  • Each of request-max-len, action-reply-max-len, the event payload maximum length and query-reply-min-len is at most CTLV_MAX_INLINE_MESSAGE_LEN.
  • A declared suggested-reply-length is at least query-reply-min-len and at most CTLV_MAX_INLINE_MESSAGE_LEN.
  • event-record-max-len is at most CTLV_MAX_EVENT_QUEUE_LEN.
  • A core-built message root has a maximum length of at most its limit (error-info: CTLV_MAX_ERROR_LEN).

13. Family registry

Documentation/ctlv/families.yaml. Top-level key families: an array of 1 to 65536 elements.

Element formMeaning
name string (at most 63 characters, name pattern)A registered family.
mapping with name and deprecated: trueA deprecated family. Its ID stays reserved.
  • The array index is the family ID.
  • The first entry is ctlv and is not deprecated.

15. ABI snapshots

A snapshot records one family's own declarations: family flags, ID and parent; definitions with value numbers; groups with attr IDs and constraints; sets; stub fills; and ops with their request and reply trees. It is written by --abi-update and compared by --abi-check.

Compared members

DeclarationRule
FamilyName, ID, parent, pre-init, post-init, pre-fini are unchanged.
Enum, flagsNot removed. Kind unchanged. Each existing value remains present with the same number.
Attr groupNot removed. Group ID unchanged.
AttrNot removed. Local ID, kind, referenced definition, unit and scale unchanged.
Attr boundsmin and min-length do not increase. max and max-length do not decrease.
max-occurrencesDoes not decrease, and does not change from unlimited to a finite value.
Blobdirection and alignment unchanged. No allowed-backings removed. max-length does not decrease.
Attr setNot removed. Set ID and stub unchanged.
Stub fillNot removed. Compared as a node list.
OpNot removed. op-id, type, fd-access, availability, optional and pre-post unchanged.
Op request, replyPresent schema not removed. An action without a reply does not gain one. Compared as a node list.
Node listNo node removed. No node changes from optional to required. reenters unchanged. A node added since the snapshot is optional.

Adding an attr, group, set, op, enum value or flag bit, or making a required placement optional, is compatible.

Registry baseline

abi/families.registry.yaml records the ordered registry. The check fails when:

  • an entry of the baseline is missing from the registry,
  • the name at an index differs,
  • a deprecated entry is no longer deprecated,
  • the registry differs from the baseline in any other way (--abi-check and --outputs-check), which requires updating the baseline.

16. Generated names

Let F be the family name with dashes replaced by underscores (upper case in macros), and X-Y a YAML name rendered as X_Y.

DeclarationName
Family numberCTLV_FAMILY_<S>, where S is the family name without a leading ctlv-; CTLV_FAMILY_ROOT for ctlv
Group<F>_GROUP_<GROUP>
Attr<F>_ATTR_<GROUP>_<ATTR> (complete ID)
Set<F>_SET_<SET>
Op<F>_OP_<OP> (complete ID)
Enum value<F>_<ENUM>_<VALUE>
Flag bit<F>_<FLAGS>_<VALUE>_BIT
Flag mask<F>_<FLAGS>_<VALUE> and <F>_<FLAGS>_MASK

In the root family, F is CTLV.

  • Two declarations that generate the same C name are an error, as is a collision with a lifecycle API symbol or a symbol of an ancestor family.
  • A generated UAPI header includes the UAPI header of its parent.
  • Each generated file begins with the license of its specification and a marker naming the specification it is generated from.

18. Root family

Family ctlv, family ID 0, specified in specs/ctlv.yaml. Its operations are inherited by every family. Its attr groups are placed inside the messages of other families.

Requirements on the root specification

  • It declares the attr set error-info.
  • Entry counts of these root enums are bounded: op-type, op-availability, op-fd-access, blob-direction at most 255; blob-type at most 15.
